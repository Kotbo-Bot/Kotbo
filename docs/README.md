# Documentation Kotbo

## Modules

  participation par giveaway : types, logique ET/OU, vérification, événement

- [`automatisations-embeds-classements.md`](./automatisations-embeds-classements.md) -

- [`detection-double-comptes.md`](./detection-double-comptes.md) - Détection de

- [`site-communautaire-spec.md`](./site-communautaire-spec.md) - Site public de

- [`outgoing-webhooks.md`](./outgoing-webhooks.md) - Webhooks sortants : format
  de la requête, signature et événements.
- [`pages-publiques.md`](./pages-publiques.md) - Classements, clans et giveaways
